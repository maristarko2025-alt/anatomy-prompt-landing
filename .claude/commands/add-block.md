# add-block — Добавить новый блок на страницу

## Что делать

1. Уточни если не хватает вводных:
   - Где находится блок (между какими секциями)?
   - Что внутри (текст, кнопка, карточки, изображение)?
   - Есть ли референс или описание внешнего вида?

2. Предложи структуру блока - сначала словами, без кода
3. Дождись моего «да»
4. Напиши HTML - с правильными семантическими тегами
5. Напиши CSS - строго через переменные из :root, без хардкода цветов
6. Покажи где именно вставить в файл (между какими комментариями-маркерами)
7. Дождись «да» перед тем как я вставляю

## Чек-лист перед сдачей блока

- [ ] Семантика: использованы правильные теги - `<section>`, `<h2>`, `<button>`, `<nav>`, не `<div>` для всего
- [ ] Кнопка - это `<button>` если не ведёт на другую страницу, и `<a>` если ведёт
- [ ] Заголовок блока - правильный уровень иерархии (после `<h1>` идёт `<h2>`, не пропускаем)
- [ ] Адаптив на 375px - блок не поплыл. Это не доработка, это часть создания
- [ ] Все цвета через переменные, border-radius строго 4px
- [ ] Маркер секции: комментарий в начале и в конце блока
- [ ] `aria-label` на интерактивных элементах без видимого текста

## Напоминание

Анимации и hover-эффекты - только если я прошу.
Никаких внешних библиотек без обсуждения.
