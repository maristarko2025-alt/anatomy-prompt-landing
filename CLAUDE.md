## Архитектура файлов

Стили в `<style>` внутри `<head>`. Скрипты перед закрывающим `</body>`.

```
anatomy-prompt-landing/
├── index.html     ← HTML + CSS + JS — всё здесь
└── README.md      ← описание проекта для GitHub
```

Пока проект однофайловый. Если потребуется разбивка на отдельные файлы — обсуждаем отдельно.

## Дизайн-система - цвета и скругления

Цвета только через переменные из `:root`. Хардкод HEX-кодов запрещён.

```css
--bg-dark: #1A1A1A        /* основной фон */
--surface-dark: #252525   /* поверхность карточек */
--border-dark: #3A3A3A    /* разделители */
--text-light: #F5F5F5     /* основной текст */
--text-muted: #8A8A8A     /* второстепенный текст */
--accent-orange: #FF9F43  /* кнопки, выделения */
--accent-teal: #00B6C9    /* hover, рамки, ссылки */
--radius: 4px             /* скругление — всегда 4px, без исключений */
```

`border-radius` строго 4px. Любое другое значение - ошибка.

## Правила работы с однофайловой структурой

**Маркеры секций** - каждая секция начинается и заканчивается чётким комментарием:
```html
<!-- ==============================
     НАЗВАНИЕ СЕКЦИИ
     Описание что внутри
     ============================== -->
...код секции...
<!-- /НАЗВАНИЕ СЕКЦИИ -->
```

**Адаптив** - это не доработка, а часть создания блока.
Не принимаю блок который «поплыл» на 375px. Мобильная версия обязательна сразу.

**Чистота при удалении** - если убираем элемент, убираем всё:
- HTML-разметку
- CSS-правила для него (включая медиазапросы)
- JS-обработчики и переменные
- Никаких «хвостов» в любой части файла

**Чистота при замене** - при замене блока проверяй что не осталось неиспользуемого CSS от старой версии.

## SEO - базовые требования

При создании или изменении блоков следи за:
- Один `<h1>` на странице - не больше
- Иерархия заголовков: `h1` → `h2` → `h3` без пропусков
- Все `<img>` с атрибутом `alt`
- `<meta name="description">` заполнен и отражает суть страницы
- Семантические теги: `<header>`, `<main>`, `<section>`, `<footer>` - не `<div>` для всего
- Атрибуты `aria-label` на интерактивных элементах без видимого текста
